# Core Python Practice

A Python learning repository containing programming exercises, NumPy practice, MySQL connector examples, file-handling exercises, and a suicide-data case-study notebook.

## Structure
- `test*.py` — core Python practice programs.
- `myfiles/` — text-file-related Python exercises.
- `numpy/` — NumPy exercises and a case-study folder.
- `db01.py`–`db04.py` — database connectivity practice.
- `Case studies/` — `Suicides_in_India.ipynb` and supporting documentation.

## Technologies
Python, NumPy, Jupyter Notebook, and MySQL Connector/Python.

## Running
`python test01.py`

NumPy example: `python numpy/test01.py`

Open `Case studies/Suicides_in_India.ipynb` with Jupyter Notebook/JupyterLab.

## Code Review Notes
This is primarily a practice repository. Some scripts currently contain errors. For example, `numpy/test01.py` contains misspelled/non-existent NumPy calls, and `db01.py` contains a hard-coded local database password. Credentials should not be committed to source control.
